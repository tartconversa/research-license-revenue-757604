# 资料口径

主体、设备和数值全部合成，不代表真实企业或实验结果。CSV 为 UTF-8，空值表示未知或不适用，不能当成零；布尔为 true/false。日期采用 ISO 格式，时刻带 +08:00 时区；日期区间左闭右开。金额为人民币元，概率为 0–1，除字段另有声明外数量为非负。CSV 排序不代表事件顺序。available_at 表示该事实最早可知时刻，历史截点不可使用较晚才知的值。样本用于开发，业务结论未预设。

result_id为成果，family_id同一成果的多证书不多算成果数。right_scope由成果、region、field及有效区间共同限定，region和field为枚举原子值，不做自然语言法律解释。exclusive同范围与其他有效许可重叠须待核；权利有冲突不删合同。bundle中相对价值权重是固定全包分母，不因缺权利把份额分光。milestone.required_deliverables逗号列出全部必须认可材料，不按交付比例确认。royalty按合同认可的原币销售额×rate，minimum是同year合同总年度保底，确认额为保底与该年累计提成较大者，不能相加；report_revision同report_key整行替代且保留历史，不与原稿累加。单体应得按收入所涉服务期间权利owner share；缺份额或无适用权利部分待分，现金保持实际到账。失效权利是否影响完整交付由合同所需成果和有效范围判定，不自动影响无关成果。

同一来源记录键的新文件表示整行修订，调用者明确接收次序；原始文件和接收历史须保留。相同文件摘要不增加事实。下面标为后续接收的文件不随基础资料自动生效，用户可分次装载。历史事实的业务时点与本次接收时点分开。金额除另述外人民币元，结算舍入到分的尾差归该账单分摊基数最大项，并列按业务键升序。本文规定来源语义，不规定待开发仓表、算法或架构。

M1是独立于年度保底/提成的交付款，保底只与同年度sales提成比较。材料R1_DOC明确属于成果R1，R2_DOC明确属于R2，不从相似材料名称猜测其他成果关系。权利有效须覆盖相应交付时点和销售范围内期间；报告跨权利变化日且无分日销售证据时，能确认的金额与待核范围分别列，不能按天数伪造实际销售。许可冲突不自动认定哪份无效，受冲突范围收入待核；共同所有者R2仅已知0.9份额，0.1待分而非归一给A/C。
